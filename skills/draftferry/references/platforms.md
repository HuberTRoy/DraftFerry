# Platform skill routing

Follow the linked skill for the platform the user selected. The platform Skills and available publishers are bundled under `platforms/`.

| Platform | Skill | Available workflow |
| --- | --- | --- |
| X | [draftferry-x](../platforms/draftferry-x/SKILL.md) | Short post over CDP |
| Bluesky | [draftferry-bluesky](../platforms/draftferry-bluesky/SKILL.md) | Short post over CDP |
| Mastodon | [draftferry-mastodon](../platforms/draftferry-mastodon/SKILL.md) | Short post over CDP |
| DEV.to | [draftferry-devto](../platforms/draftferry-devto/SKILL.md) | API Key preflight and Markdown publication |
| Medium | [draftferry-medium](../platforms/draftferry-medium/SKILL.md) | Markdown draft and publication through CDP; public URL import available |
| Substack | [draftferry-substack](../platforms/draftferry-substack/SKILL.md) | Markdown draft or web-only article over CDP |
| Tumblr | [draftferry-tumblr](../platforms/draftferry-tumblr/SKILL.md) | Markdown to rich text through CDP |
| Blogger | [draftferry-blogger](../platforms/draftferry-blogger/SKILL.md) | Markdown to rich text through CDP |
| beehiiv | [draftferry-beehiiv](../platforms/draftferry-beehiiv/SKILL.md) | Markdown to rich text through CDP, web only |
| Hashnode | [draftferry-hashnode](../platforms/draftferry-hashnode/SKILL.md) | Markdown draft or article over CDP with a configured publication |

Run the publishers from the DraftFerry Skill directory. Put source input and any existing receipts needed to resume an earlier publishing run under `artifacts/`.
